# Flattening-Toolset
Professional UV Tools for Shoe Designers FTW Flattening Toolset is a comprehensive UV editing suite perfect for shoe design workflows.

## ✨ Features

### UV Editing Tools (UV Editor Panel)
- **Unwrap** - Angle-based unwrapping with Live Unwrap toggle
- **Pin/Unpin** - Mark vertices for controlled unwrapping
- **Flatten to Center** - Flatten UVs with edge preservation
- **Mirror Pairs** - Set up symmetrical UV unwrapping (X/Y axis)
- **UV Labels** - Island naming and organization
- **Minimize Stretch** - Relax and optimize UVs
- **Scale to Canvas** - Real-world size scaling (cm)

### Visualization & Export
- **Canvas Checker** - Procedural checker texture for distortion checking
- **2D Curves Export** - Export UV boundaries as curves with subdivision

### Dual Panel Interface
1. **UV Editor Panel** - "FTW UV Flattening" tab
   - Full toolset for UV editing   
2. **3D View Panel** - "FTW Checker"
   - Canvas Size setting
   - Checker toggle (Show/Hide)

## 🔧 Technical Details

### Canvas Checker
- Procedural generation
- Each square = 1cm of canvas size
- Instant toggle in Solid shading mode

### 2D Curves
- Applies subdivision with corner preservation
- Extracts boundary edges as POLY curves
- Includes canvas border

### System Requirements
- **Blender:** 5.0.0 or higher
- **Platform:** Windows, Mac, Linux
- **Mode:** Works in Edit mode (UV Editor), Object/Edit mode (3D View)
